01 / INTERPRETATION

原文与候选代码分开。

论文 A3 描述固定物体轨迹优化手部。候选代码在特定任务额外执行 touch-table grounding；该分支单列为 Grounding＋A3，另提供 paper-fixed-objects 严格对照。

02 / TEACHER INPUT

深度尺度统一。

论文相对深度使用对齐后的 MoGe 深度。新分支 Scene / A2 使用已生成的 aligned-depth 输入，历史 raw-depth 结果保持可追溯。

03 / LIMITATIONS

视觉质量仍有差距。
